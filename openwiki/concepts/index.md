# Files

- [Backends](backends.md) - DeepAgents backends define file storage, persistence scope, virtual-path routing, artifact placement, and optional command execution. This page explains the backend contract, composite mounts, binary-content offload, and Talon's host-versus-sandbox routing and lifecycle.
- [Deep Agents Code Configuration Layering](config-layering.md) - How dcode combines managed policy, command-line values, environment variables, user TOML, project dotenv files, credentials, and server handoff configuration. Covers precedence, reload safety, workspace isolation, and fail-closed controls.
- [Context Management](context-management.md) - Deep Agents keeps model requests within usable context through recoverable result eviction, event-based conversation compaction, media archival, and bounded overflow recovery. It documents the model-aware defaults and shared state contract for automatic and manual compaction.
- [Middleware Catalog](middleware-catalog.md) - Deep Agents middleware responsibilities, assembly order, state ownership, and request and tool boundaries, including context compaction and synchronous or remote subagents.
- [Permissions and Human-in-the-Loop](permissions-hitl.md) - Explains Deep Agents filesystem permission enforcement and HITL routing, including local and remote subagent boundaries. Distinguishes SDK controls from dcode Manual, Auto, and YOLO approval behavior and Talon channel approvals.
- [Models, Profiles, and Provider Configuration](profiles-models.md) - Describes server-owned model discovery and safe client presentation data, model construction and request-time switching, retry ownership, and prompt-cache identity state. Explains the boundaries between capability profiles, credentials, constructor settings, and persisted session metadata.
- [State, Checkpoints, and Sessions](state-persistence.md) - Explains how LangGraph checkpoints, dcode's local SQLite sessions, thread ownership fencing, durable titles, and separate graph stores relate. Covers restoration, isolation, deletion, inspection, and the distinct Talon persistence model.
- [Subagents and Skills](subagents-skills.md) - Deep Agents separates synchronous and remote delegation across explicit state and lifecycle boundaries. Skills expose instructions progressively and disclose selected tools only after a visible read or pin, with provider-aware payload placement and recorded tool-time gating.
- [Talon Channel Admission](talon-channel-admission.md) - How Talon channel adapters admit messages and reactions, bind trusted conversation identity to host-owned turns, and constrain cancellation, authorization, and delivery. Covers pairing, media boundaries, and request-scoped privileged responses.
- [Talon Scheduling and Background Work](talon-scheduling.md) - Talon persists origin-scoped cron jobs, claims them before unattended execution, and routes non-silent results to their recorded origin. This page covers schedule semantics, storage and recovery, delivery, pinned skills, and the distinct background-subagent behavior of chat and cron turns.
- [Filesystem Tools and Policies](tools-filesystem.md) - FilesystemMiddleware turns backend file operations into model-facing tools and applies capability, path-policy, content, and compatibility controls. FilesystemBackend supplies direct host storage with virtual-path semantics that are useful but are not process isolation.
