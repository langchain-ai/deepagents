# Incident summary

1. Read the team conventions in `/memories/agent/AGENTS.md`. They override the defaults below.
2. Ask for missing facts only if the impact or the trigger is unknown.
3. Write the summary with these default sections:
   - **Impact**: who was affected, for how long, and how badly.
   - **Timeline**: detection, mitigation, and resolution times.
   - **Root cause**: the triggering change or condition.
   - **Follow-ups**: concrete actions that prevent a repeat.
4. Keep it under 200 words unless the user asks for more detail.
