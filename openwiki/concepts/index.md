- [Talon Channel Admission](talon-channel-admission.md) - How Talon channel adapters admit provider events and how TalonHost binds those events to safe conversations, approvals, interactive questions, runtime turns, cancellation, and delivery.

- [Talon Scheduling and Background Work](talon-scheduling.md) - How Talon persists and executes unattended cron jobs, routes their results, and distinguishes scheduled inline delegation from process-local attended-chat subagents. - [Tools and Filesystem Access](tools-filesystem.md) - Deep Agents and dcode expose filesystem and execution tools through capability-aware middleware backed by pluggable storage and sandbox implementations. This page explains tool allowlists, routing, permission and approval controls, search deadlines, content lifecycle, media reads, and containment boundaries.
- [Trace Attribution](trace-attribution.md) - How dcode uses bounded Git checkout evidence to label the traced work of one agent turn without affecting tool execution. Covers middleware installation, per-turn baselines, privacy limits, failure backoff, and retrospective LangSmith metadata updates.
