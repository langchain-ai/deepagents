- [Profiles and Models](profiles-models.md) - Explains SDK provider and harness profiles, dcode model construction and retry ownership, package compatibility, and Talon's per-chat model selection. Distinguishes construction-time configuration from graph behavior and model-dependent runtime state.

- [Subagents and Skills](subagents-skills.md) - Deep Agents separates synchronous local delegation from durable remote async tasks, including task observation and guarded parent wake-ups. Skills progressively disclose instructions and optionally tools, without granting authorization.
- [Talon Channel Admission](talon-channel-admission.md) - Discord admission and interaction routing in Talon, from provider events through host-owned conversations, pairing, thread context, and failure-safe delivery. Explains the access policy boundary and request-bound privileged responses.
- [Talon Scheduling and Background Work](talon-scheduling.md) - Talon persists origin-scoped cron jobs, claims them before unattended execution, and routes non-silent results to their recorded origin. This page covers schedule semantics, storage and recovery, delivery, pinned skills, and the distinct background-subagent behavior of chat and cron turns.
- [Tools and Filesystem](tools-filesystem.md) - FilesystemMiddleware exposes backend-backed file tools while separately applying model-surface filtering, filesystem policy, human approval, and content lifecycle controls. Composite routing remaps file paths across backends, whereas execution remains attached to the composite default backend.
