# Files

- [Backends and Durable File State](backends.md) - BackendProtocol provides a common virtual file interface. StateBackend keeps files in a graph thread's state, while StoreBackend scopes durable cross-thread records by namespace and both safely read legacy list-based content until a write or edit migrates it.
- [Deep Agents Code Configuration Layering](config-layering.md) - How dcode combines managed policy, command-line values, environment variables, user TOML, project dotenv files, credentials, and server handoff configuration. Covers precedence, reload safety, workspace isolation, and fail-closed controls.
- [Context Management](context-management.md) - Deep Agents keeps model requests within usable context through recoverable result eviction, event-based conversation compaction, media archival, and bounded overflow recovery. It documents the model-aware defaults and shared state contract for automatic and manual compaction.
- [Middleware Catalog](middleware-catalog.md) - Public Deep Agents middleware catalog, default graph assembly, and the state and execution boundaries for context management and subagent delegation.
- [Permissions and Human-in-the-Loop](permissions-hitl.md)
- [Profiles and Models](profiles-models.md) - Explains SDK provider and harness profiles, dcode model construction and retry ownership, package compatibility, and Talon's per-chat model selection. Distinguishes construction-time configuration from graph behavior and model-dependent runtime state.
- [State, Checkpoints, and Sessions](state-persistence.md) - Explains how LangGraph checkpoints, dcode's local SQLite sessions, thread ownership fencing, durable titles, and separate graph stores relate. Covers restoration, isolation, deletion, inspection, and the distinct Talon persistence model.
- [Subagents and Skills](subagents-skills.md) - Deep Agents separates synchronous local delegation from durable remote async tasks, including task observation and guarded parent wake-ups. Skills progressively disclose instructions and optionally tools, without granting authorization.
- [Talon Channel Admission](talon-channel-admission.md) - Talon channel admission, provider routing, pairing, and host-owned conversation controls. Covers the separate per-process verbosity setting for interim channel updates, not access or approval policy.
- [Talon Scheduling and Background Work](talon-scheduling.md) - Talon persists origin-scoped cron jobs, claims them before unattended execution, and routes non-silent results to their recorded origin. This page covers schedule semantics, storage and recovery, delivery, pinned skills, and the distinct background-subagent behavior of chat and cron turns.
- [Tools and Filesystem](tools-filesystem.md) - FilesystemMiddleware exposes backend-backed file tools while separately applying model-surface filtering, filesystem policy, human approval, and content lifecycle controls. Composite routing remaps file paths across backends, whereas execution remains attached to the composite default backend.
