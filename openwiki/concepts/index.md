# Files

- [Backends (Filesystem, State, Store, Sandbox)](backends.md) - How deepagents' pluggable BackendProtocol decides where agent files, memory, and shell execution live — covering the state, store, filesystem, sandbox, composite, langsmith, local_shell, and context_hub implementations and how the resolved backend fixes durability and shell availability.
- [dcode Configuration Model](config-layering.md) - dcode resolves typed settings through ranked providers while retaining one shared file-snapshot generation. This page explains precedence, managed-policy failure retention, runtime reload overrides, and the limited callers that intentionally inspect independent snapshots.
- [Context Management](context-management.md) - How deepagents reduces model-visible context through tool-result eviction, summarization, and overflow recovery, and how dcode adds a hook-aware server-owned offload protocol. It distinguishes recoverable archives from LangGraph checkpoint state and documents commit and failure behavior.
- [Middleware Catalog](middleware-catalog.md) - Compact index of built-in deepagents middleware, its assembly boundaries, and the configuration points that change the tools and context an agent receives.
- [Permissions & Human-in-the-Loop](permissions-hitl.md) - How deepagents enforces filesystem permissions at tool execution time and converts interrupt rules into human approval. It also describes dcode approval modes, live policy storage, and agent-initiated ask_user interruptions.
- [Profiles & Model Resolution](profiles-models.md) - How Deep Agents turns a model string into a configured chat model and tunes runtime behavior via two orthogonal profile systems — provider profiles (model construction) and harness profiles (prompt, tools, middleware).
- [State Persistence](state-persistence.md) - Explains checkpoint ownership, delta-reduced graph state, backend durability, subagent state transfer, and dcode session persistence. Includes the ACP checkpointer lifetime and session-local graph construction.
- [Subagents & Skills](subagents-skills.md) - How Deepagents delegates work to isolated, forked, compiled, and remote asynchronous subagents, and exposes reusable skills through progressive disclosure. Covers validation, state and result boundaries, inheritance, and operational behavior.
- [Tool Surface & Filesystem Tools](tools-filesystem.md) - How the model's visible tool set is assembled from middleware, caller tools, backend capability, and profile exclusions, and how the built-in filesystem tools and their permission checks behave.
