This page covers lifecycle, local-time behavior, retention, and pairing-revocation controls.
- [Filesystem and Execution Tools](tools-filesystem.md) - FilesystemMiddleware exposes backend-backed file and optional shell tools, validates their results and capabilities, and controls how large text and binary media survive model requests and checkpoints.
