# Files

- [Backends and Capability Routing](backends.md) - DeepAgents backends determine file storage, persistence scope, path routing, and whether the filesystem middleware can expose shell execution. Isolation is established by the selected backend and sandbox, not by model intent or virtual paths.
- [Configuration Layering and Workspace Binding](config-layering.md) - How dcode resolves ranked configuration, safely writes and reloads TOML policy, controls MCP trust and disablement, and binds server runtimes to workspace policy with drift diagnostics.
- [Context Management](context-management.md) - Deep Agents keeps model requests within usable context limits through recoverable filesystem eviction, summary events, and bounded overflow recovery. It explains artifact placement, state ownership, sync/async invariants, and failure behavior.
- [Middleware Catalog](middleware-catalog.md) - Catalog of Deep Agents middleware by lifecycle hook, state and prompt effects, public exports, ordering constraints, and the boundary between middleware capabilities and caller-provided tools.
- [Permissions and Human Approval](permissions-hitl.md) - Explains the distinct availability, approval, authorization, and containment layers across Deep Agents, dcode, and Talon. Details Talon's exact-name approval snapshots, trusted operator authority, host-mediated decisions, model switching, and fail-closed unattended work.
- [Models and Harness Profiles](profiles-models.md) - Explains Deep Agents model resolution, provider-construction profiles, and harness profiles that overlay prompts, middleware, and request-time tool visibility. Also covers dcode model construction, runtime switching, and resume-safe per-call settings.
- [State and Persistence](state-persistence.md) - Explains Talon's assistant-owned state, SQLite graph checkpoints, scoped conversation archives, URI-selected history backends, vector indexes, and durable operational files.
- [Subagents and Skills](subagents-skills.md) - Deep Agents delegates synchronous isolated or forked work through a task tool and can track remote Agent Protocol work asynchronously. Skills are a separate backend-discovery and prompt-index mechanism, with explicit state and propagation boundaries.
- [Talon Channel Admission, Pairing, and Delivery](talon-channel-admission.md) - How Talon channel adapters admit provider events, distinguish sender access from operator authority, and route host-owned conversations, commands, reactions, replies, and media.
- [Talon Scheduled Work and Cron Semantics](talon-scheduling.md) - Persistent Talon cron jobs, their schedule grammar and durable lifecycle, and the limits that apply when an unattended job invokes and delivers through a channel host.
- [Filesystem and Tool Surface](tools-filesystem.md) - How Deep Agents and dcode compose model-visible tools, route filesystem operations through backends, and keep capabilities, permissions, HITL approval, and MCP access distinct.
