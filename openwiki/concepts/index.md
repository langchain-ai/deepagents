# Files

- [Backends and Durable File State](backends.md) - BackendProtocol unifies virtual file operations while separating shell-capable backends from state and store persistence. This guide covers file compatibility, routing, durable scopes, Context Hub commits, and the severe operational risks of local shell execution.
- [dcode Configuration Layering](config-layering.md) - How dcode resolves typed configuration across managed policy, CLI values, environment, user TOML, and defaults. Covers generation and reload semantics, project dotenv and trust boundaries, and client-to-server workspace policy.
- [Context Management](context-management.md) - Deep Agents limits model-context pressure with recoverable result and binary offload, event-based conversation compaction, and bounded overflow recovery. Deep Agents Code adds server-owned manual and idle offload with durable local archive handling.
- [Middleware Catalog](middleware-catalog.md) - A catalog of Deep Agents middleware, with ordered graph assembly and focused guidance for automatic or manual context compaction and optional remote asynchronous delegation.
- [Permissions and Human-in-the-Loop](permissions-hitl.md)
- [Profiles and Models](profiles-models.md) - Explains the boundary between Python package dependencies, dcode model discovery and policy, SDK model-construction profiles, and Deep Agents harness profiles. Describes how model specifications become configured models and then agent graphs.
- [State, Checkpoints, and Persistence](state-persistence.md) - Distinguishes LangGraph checkpointed graph state from backend storage and documents how dcode sessions and Talon archive conversation state independently.
- [Subagents, Skills, and Delegation](subagents-skills.md) - Deep Agents separates isolated local delegation from durable Agent Protocol async tasks, with distinct polling, direct wake-up, and webhook delivery paths. Skills progressively disclose instructions and optional tools without granting authorization.
- [Talon Channel Admission](talon-channel-admission.md) - Talon channel admission, provider routing, pairing, and host-owned conversation controls. Covers the separate per-process verbosity setting for interim channel updates, not access or approval policy.
- [Talon Scheduling and Background Work](talon-scheduling.md) - How Talon persists and executes unattended cron jobs, routes their output, and distinguishes scheduled delegation from detached chat subagents. Covers delivery, approval limits, retries, result handoff, and safe shutdown.
- [Tool Surface and Filesystem Policy](tools-filesystem.md) - FilesystemMiddleware exposes backend-backed file tools while separately applying model-surface filtering, filesystem policy, human approval, and content lifecycle controls. Composite routing remaps file paths across backends, whereas execution remains attached to the composite default backend.
